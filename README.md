# Group Sprint 2
Team: Don, Dylan, Luke, Pietro

## Can Graph Neural Networks (GNN) improve expected goals (xG) prediction by modelling the spatial relationships between players at the moment of a shot?

This project is a step up from our Sprint 1 concept. Using GNN, we aim to do the following:
- Using player positions and shot characteristics to predict goal probability.
- Modelling interactions between attackers, defenders and goalkeepers.
- Comparing graph-based learning against a model that does not use message passing.
- Evaluating whether the additional complexity produces better predictions.
